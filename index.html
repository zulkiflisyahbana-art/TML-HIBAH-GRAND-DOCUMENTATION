Disimpan di perangkat

Pengaturan

Pengaturan ini tersimpan di browser perangkat ini.

Klik ▾ pada kolom untuk memilih data yang pernah dipakai. Jika belum ada, ketik langsung. Isian otomatis tersimpan sebagai draf di perangkat ini.

Langkah awal: unggah dokumen sumber

Semua data di bawah mengacu pada dokumen sumber: B/L, MoU, NPWP, dan dokumen lain. Unggah dulu, lalu isi data sambil membuka dokumen dengan tombol Lihat. Aplikasi tidak membaca isi PDF atau gambar otomatis. Lampiran tersimpan di browser perangkat ini.

Data proyek

Shipper dan Consignee

Unit kendaraan

Dokumen lampiran

Dokumen pembanding (opsional)

Ketik ulang data dari Bill of Lading dan MoU agar aplikasi bisa mencocokkan dengan isi form. Pencocokan dilakukan terhadap data yang Anda ketik, bukan membaca file dokumen.

Pemeriksaan otomatis

Laporan verifikasi

VERIFIED = lolos pemeriksaan otomatis. NEED CONFIRMATION = cocokkan dengan dokumen sumber. Aplikasi tidak menentukan sendiri data mana yang benar. Klik Edit pada baris untuk langsung memperbaiki datanya.

Jejak aktivitas

Dicatat otomatis: simpan, konfirmasi, unduh, dan arsip. Nama diambil dari Pengaturan (belum terotentikasi).

Excel belum dapat dibuat

Selesaikan verifikasi lebih dulu, lalu klik Telah Dikonfirmasi di tab Verifikasi.

Pratinjau di bawah menggambar ulang template Excel TML dengan data Anda. Tampilan cetak resmi mengikuti file .xlsx.

Arsip proyek

Satu paket berisi dokumen sumber, Excel, PDF, laporan verifikasi, data proyek, jejak aktivitas, dan ringkasan, dalam struktur TML HIBAH / tahun / nama proyek.
